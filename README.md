A one-line vending machine pickup line for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty, $2 in USDC. The program writes the line to `/output/entry.txt`, deterministically, with no network and no randomness.

> You walked past and my coils spun before you even pressed a button — guess I dispense crushes now.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The entry is 98 characters — inside the 1–200 gate, UTF-8, exactly one line.

## Why this line

Most vending machine pickup lines reach for the same two moves: "Are you a snack?" or "press my buttons." This one flips the machine's job instead. The machine doesn't offer a snack or ask to be pressed — it malfunctions out of attraction. Its coils spin before anyone has touched a button, and it ends up dispensing something it was never stocked with: a crush.

Everything in the line comes from the machine's own world — coils, buttons, dispensing — spoken in the machine's own first-person voice, with the punch landing in the last few words. Short enough to read in one breath, and warm rather than creepy: the machine is smitten, not staking a claim.
